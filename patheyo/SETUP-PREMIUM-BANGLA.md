# প্রিমিয়াম সদস্যের হিসাব — একবারের সেটআপ

অ্যাডমিন প্যানেলের **প্রিমিয়াম** ট্যাবে দেখা যায়:
- সক্রিয় সদস্য, প্ল্যান অনুযায়ী সংখ্যা, কতজনের মেয়াদ শিগগিরই শেষ হবে, কতজন নবায়ন করেননি
- আয়: আজ, এ মাস, গত মাসের তুলনা, মোট আয়, MRR, ১২ মাসের চার্ট, পেমেন্টের মাধ্যম, গেটওয়ে ফি বাদে নিট আয়
- সদস্য তালিকা: কার কত দিন বাকি (অগ্রগতি-বার সহ), CSV এক্সপোর্ট
- নোটিফিকেশন: সব সদস্য / প্ল্যান অনুযায়ী / ৭ বা ৩০ দিনে মেয়াদ শেষ / মেয়াদ শেষ হওয়া / নির্দিষ্ট সদস্য কোড

## গোপনীয়তা
- কোনো নাম, ইমেইল, ফোন নম্বর বা Firebase uid অ্যাডমিন প্যানেলে বা Supabase-এ যায় না।
- প্রতিটি সদস্য একটি বেনামী **সদস্য কোড** (যেমন `PM-3F9A-C21B`) দিয়ে চেনা হয়। এটি uid-এর একমুখী হ্যাশ, তাই কোড থেকে অ্যাকাউন্ট বের করা যায় না।
- সদস্য অ্যাপের প্রিমিয়াম পাতায় নিজের কোড দেখতে পান। সহায়তা চাইলে কোডটি জানালে তবেই আপনি তাকে খুঁজে পাবেন।

## ধাপ ১ — টেবিল বানানো
Supabase → SQL Editor → New query → `patheyo/supabase/premium.sql` পুরোটা পেস্ট করে **Run**।

## ধাপ ২ — ফাংশন ডিপ্লয়
```
supabase functions deploy premium-admin --no-verify-jwt
```
নতুন কোনো সিক্রেট লাগে না। `send-push`-এর জন্য বসানো `FCM_SERVICE_ACCOUNT` (একই Firebase প্রজেক্টের সার্ভিস অ্যাকাউন্ট) দিয়েই চলে।
Firebase ডাটাবেসের ঠিকানা আলাদা হলে `RTDB_URL` সিক্রেট বসান (ডিফল্ট: `https://hijri-tarikh-default-rtdb.firebaseio.com`)।

## ধাপ ৩ — অ্যাপ v274
নির্দিষ্ট সদস্যদের নোটিফিকেশন পাঠাতে অ্যাপ **Patheyo_v274** বা নতুন লাগবে। এই ভার্সন থেকে অ্যাপ নিজে প্রিমিয়াম টপিকে যুক্ত হয়:
`premium`, `premium_monthly` / `premium_yearly` / `premium_lifetime`, এবং `pm_<কোড>`।
পুরনো অ্যাপের সদস্যরা হিসাবে দেখা যাবেন, তবে নোটিফিকেশন পাবেন অ্যাপ আপডেট ও একবার খোলার পর।

## কীভাবে কাজ করে
1. **সিঙ্ক** বাটন (ট্যাব খুললে ১৫ মিনিট পরপর নিজেও চলে) Firebase-এর `orders` (paid), `play_tokens` ও `users/*/premium` পড়ে।
2. সেখান থেকে শুধু সদস্য কোড, প্ল্যান, শুরু, মেয়াদ, উৎস ও পেমেন্টের অঙ্ক Supabase-এর `premium_members` / `premium_payments`-এ রাখে।
3. Google Play-র কেনার অঙ্ক এখানে প্ল্যানের দাম ধরে **আনুমানিক** (≈)। আসল অঙ্ক Play Console-এ দেখুন।
4. Firebase Console থেকে হাতে কাউকে প্রিমিয়াম দিলে তা ধরতে **সম্পূর্ণ স্ক্যান** টিক দিয়ে সিঙ্ক করুন (সময় বেশি লাগে)।

সেটআপ ঠিক আছে কি না: অ্যাডমিন → **সেটআপ** ট্যাবে "প্রিমিয়াম হিসাব" ও "প্রিমিয়াম ফাংশন" দুটোতেই ✓ আসা উচিত।

## ডোনেশন তালিকা (অ্যাডমিন প্যানেল → "ডোনেশন" ট্যাব)
- অ্যাপ ও ওয়েবসাইট থেকে আসা ডোনেশন Firebase-এর `donations/`-এ থাকে (পেমেন্ট সার্ভার লেখে)। অ্যাডমিন প্যানেল `premium-admin` ফাংশনের `donations` কাজ দিয়ে সেটা সরাসরি পড়ে — Supabase-এ কিছু কপি হয় না, নতুন SQL লাগে না।
- এর জন্য `premium-admin` ফাংশনটা নতুন কোড দিয়ে **একবার আবার ডিপ্লয়** করুন (ড্যাশবোর্ড → Edge Functions → premium-admin → কোড বদলে Deploy, অথবা `npx supabase functions deploy premium-admin --no-verify-jwt`)।
- তালিকায় শুধু অঙ্ক, পদ্ধতি, অ্যাপ/ওয়েবসাইট, অবস্থা ও সময় — দাতার কোনো ব্যক্তিগত তথ্য নেই।
